# TCL 55Q6C QD-Mini LED, India (device G08, model "Smart TV Pro", product G08_4K_GB, MediaTek tcl9618)
# Google TV, Android 14 (SDK 34), firmware UTT2.250416.001 AU02 - the same build as examples/tcl-q7c-google-tv.
# About 2.4 GB RAM. On Wi-Fi, PS5 on HDMI 1. Indian apps kept: JioHotstar, JioCinema, Airtel Xstream, SonyLIV.
#
# Tested on one set from 22 October 2026. Disabled with `pm disable-user --user 0`, one call each, in three batches
# with a screenshot after each, then one reboot: all 25 stayed off, none came back. MemAvailable on Home went from
# about 640 MB to about 890-920 MB. launcherx and setupwraith were disabled afterwards, for the new launcher.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-55q6c-google-tv/debloat.txt
#          On Wi-Fi, check `dumpsys wifi | grep cname` first: here the home network belonged to setupwraith until
#          it was forgotten and re-joined in Settings (README). launcherx is skipped by disable.sh's Home guard
#          until the new launcher is Home; build-and-install.sh disables it.
# Undo:    TV_HOST=<tv ip> examples/tcl-55q6c-google-tv/restore-all.sh
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / HDMI app: com.tcl.tv (com.tcl.player.TVActivity).
# Left enabled on purpose: com.tcl.tv, com.tcl.tvinput, com.tcl.suspension (Input key menu), com.tcl.autopair
